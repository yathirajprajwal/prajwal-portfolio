Personal project

Shui.AI, an AI teammate that joins your meetings.

I built it solo, end to end in .NET 10. Say "Hey Shui" in a Google Meet call and it answers out loud from the team's own code, pull requests, issues and docs, with a source for every claim.

said "shoo-ee"
invite
  1. Step 1

    It joins by itself

    Add Shui to a Calendar event, or use Meet's "Add people" mid-call. It joins on its own browser profile, several calls at once.

  2. Step 2

    It listens and waits its turn

    Shui reads Meet's live captions, waits for people to finish, and stops if someone starts talking.

  3. Step 3

    It answers with sources

    Hybrid search over your repos, filtered by who may see what. It speaks the answer and posts the sources in the chat. No source, no answer.

  4. Step 4

    It writes the notes

    Summary, decisions and action items when the call ends, indexed so later questions can cite them.

What I built it with

.NET 10, ASP.NET Core MVC
Razor views, a JSON API and background workers in one classic .sln.
Microsoft.Extensions.AI
One interface for every model, so switching providers is configuration.
PostgreSQL + pgvector
Vector and full-text search merged with reciprocal rank fusion.
Free model chain
Gemini, Groq, Cerebras, OpenRouter and Mistral free tiers, then local Ollama.
Playwright
Drives a real Edge or Chrome window into Google Meet.
Kokoro TTS, SearXNG
A self-hosted voice and private web search with no API key.
MailKit, Ical.Net
Reads calendar and Meet invitations so Shui joins on its own.
OpenID Connect
Google or Entra sign-in, per-user rate limits, an audit log of every answer.
Docker, Caddy, GitHub Actions
One-command deploy with HTTPS, and CI running 80+ xUnit tests.
